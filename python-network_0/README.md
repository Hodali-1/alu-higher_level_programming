# Python - Network #0

This project covers HTTP fundamentals: URLs, requests, responses,
headers, status codes, and cookies, using curl from Bash scripts to
send GET, DELETE, POST, and OPTIONS requests.

## Requirements
- Editors: `vi`, `vim`, `emacs`
- All scripts tested on Ubuntu 20.04 LTS
- All Bash scripts are exactly 3 lines long (`wc -l file` prints 3)
- All files end with a new line and must be executable
- First line of every Bash file: `#!/bin/bash`
- Second line: a comment explaining what the script does
- Every `curl` command uses `-s` (silent mode)
