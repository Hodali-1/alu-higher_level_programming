# SQL Introduction

This project covers the basics of relational databases and SQL: what a
database and a relational database are, DDL vs DML, creating databases
and tables, and basic SELECT/INSERT/UPDATE/DELETE queries in MySQL.

## Requirements
- Editors: `vi`, `vim`, `emacs`
- All files executed on Ubuntu 20.04 LTS using MySQL 8.0 (version 8.0.25)
- All files should end with a new line
- All SQL queries should have a comment just before them
- All files should start with a comment describing the task
- All SQL keywords should be in uppercase (SELECT, WHERE...)
- The length of files is tested using `wc`
