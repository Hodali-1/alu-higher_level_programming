# JavaScript - Web jQuery

Scripts for the ALU JavaScript web jQuery project (Chrome, jQuery 3.x, semistandard with `--global $`).

| File | Description |
| ---- | ----------- |
| 0-script.js | Turns the header red using document.querySelector (no jQuery) |
| 1-script.js | Turns the header red using jQuery |
| 2-script.js | Turns the header red when DIV#red_header is clicked |
| 3-script.js | Adds the class red to the header when DIV#red_header is clicked |
| 4-script.js | Toggles the header class between red and green on click |
| 5-script.js | Adds an LI "Item" to UL.my_list when DIV#add_item is clicked |
| 6-script.js | Sets the header text to "New Header!!!" on click |
| 7-script.js | Fetches a Star Wars character name into DIV#character |
| 8-script.js | Lists all Star Wars film titles in UL#list_movies |
| 9-script.js | Fetches "hello" in French into DIV#hello (runs on DOM ready) |
