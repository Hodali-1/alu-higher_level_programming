# JavaScript - Objects, Scopes and Closures

Scripts for the ALU JavaScript objects, scopes and closures project (node 14.x, semistandard).

| File | Description |
| ---- | ----------- |
| 0-rectangle.js | Empty class Rectangle |
| 1-rectangle.js | Rectangle with width and height |
| 2-rectangle.js | Rectangle that is empty if w or h is not a positive integer |
| 3-rectangle.js | Adds print() using the character X |
| 4-rectangle.js | Adds rotate() and double() |
| 5-square.js | Square that extends Rectangle |
| 6-square.js | Square with charPrint(c) |
| 7-occurrences.js | Counts occurrences of an element in a list |
| 8-esrever.js | Reverses a list without using reverse |
| 9-logme.js | Logs a counter and the argument (closure over module state) |
| 10-converter.js | Returns a function that converts a number to a given base |
