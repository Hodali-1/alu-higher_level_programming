The ``1-my_list`` module
=========================

Using ``MyList``
-----------------

Import MyList:

    >>> MyList = __import__('1-my_list').MyList

Create a MyList and append some integers:

    >>> my_list = MyList()
    >>> my_list.append(1)
    >>> my_list.append(4)
    >>> my_list.append(2)
    >>> my_list.append(3)
    >>> my_list.append(5)
    >>> print(my_list)
    [1, 4, 2, 3, 5]

Print it sorted, without changing the original order:

    >>> my_list.print_sorted()
    [1, 2, 3, 4, 5]
    >>> print(my_list)
    [1, 4, 2, 3, 5]

An empty MyList prints sorted as an empty list:

    >>> MyList().print_sorted()
    []
