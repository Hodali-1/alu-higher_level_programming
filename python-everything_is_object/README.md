# Python - Everything is object

This project explores Python's object model: what `id()` and `type()`
reveal about an object, the difference between mutable and immutable
objects, how assignment differs from copying, how CPython's small
integer cache works, and how arguments are passed to functions.

## Requirements
- Editors: `vi`, `vim`, `emacs`
- Interpreted on Ubuntu 20.04 LTS, python3 (version 3.8.5)
- All files end with a new line
- Code follows pycodestyle (version 2.7.*)
