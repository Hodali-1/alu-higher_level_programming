# Python - More Classes and Objects

This project goes deeper into Object-Oriented Programming in Python by
building a `Rectangle` class incrementally: private attributes with
property getters/setters, `__str__` and `__repr__`, class attributes,
`__del__`, static methods, and class methods.

## Requirements
- Editors: `vi`, `vim`, `emacs`
- Interpreted on Ubuntu 20.04 LTS, python3 (version 3.8.5)
- All files end with a new line
- First line of every file: `#!/usr/bin/python3`
- Code follows pycodestyle (version 2.7.*)
- All files are executable
- Every module, class, and function has a real, descriptive docstring
