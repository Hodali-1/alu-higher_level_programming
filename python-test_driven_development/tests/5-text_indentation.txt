The ``5-text_indentation`` module
====================================

    >>> text_indentation = __import__('5-text_indentation').text_indentation

A short sentence ending in each punctuation mark:

    >>> text_indentation("Hi there. How are you? See you: bye")
    Hi there.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    See you:
    <BLANKLINE>
    bye
