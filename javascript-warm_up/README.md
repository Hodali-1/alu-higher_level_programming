# JavaScript - Warm up

Scripts for the ALU JavaScript warm-up project (node 14.x, semistandard).

| File | Description |
| ---- | ----------- |
| 0-javascript_is_amazing.js | Prints "JavaScript is amazing" using a constant |
| 1-multi_languages.js | Prints 3 lines about C, Python and JavaScript |
| 2-arguments.js | Prints a message based on the number of arguments |
| 3-value_argument.js | Prints the first argument, or "No argument" |
| 4-concat.js | Prints "<arg1> is <arg2>" |
| 5-to_integer.js | Prints the first argument as an integer, or "Not a number" |
| 6-multi_languages_loop.js | Same as task 1, with an array and a loop |
| 7-multi_c.js | Prints "C is fun" x times |
| 8-square.js | Prints a square of X characters |
| 9-add.js | Adds two integers |
| 10-factorial.js | Recursive factorial |
| 11-second_biggest.js | Second biggest integer in the arguments |
| 12-object.js | Updates an object value from 12 to 89 |
| 13-add.js | Exports an `add` function (tested by 13-main.js) |
