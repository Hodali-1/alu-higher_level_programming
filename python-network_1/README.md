# Python - Network #1

This project goes deeper into HTTP from Python: fetching URLs and
reading response bodies/headers with both the standard library
(`urllib`) and the `requests` library, handling HTTP errors, sending
POST requests, parsing JSON responses, and using the GitHub API with
Basic Authentication.

## Requirements
- Editors: `vi`, `vim`, `emacs`
- Interpreted on Ubuntu 20.04 LTS using python3 (version 3.8.5)
- First line of every file: `#!/usr/bin/python3`
- Code follows pycodestyle (version 2.7.*)
- All files end with a new line and must be executable
- Every module and function has a real, descriptive docstring
